# Hello, World 👋

My first repository on GitHub, and the start of my public work as a systems and network security engineer.

## What this repo is

A small starting point to check that my GitHub setup works: a simple PowerShell script, a README and my first commit.

## Try it

```powershell
.\Hello-World.ps1
```

`Hello-World.ps1`:

```powershell
$name = "World"
Write-Host "Hello, $name! Running on $env:COMPUTERNAME at $(Get-Date -Format 'yyyy-MM-dd HH:mm')."
```

Expected output (your computer name and time will differ):

```
Hello, World! Running on MY-PC at 2026-10-07 10:20.
```

Requires Windows PowerShell 5.1 or PowerShell 7.
